# GEO 分析功能需求整理

來源：`20260617開會簡報.pdf`，2026-06-17 GEO 能見度檢測工具自研產品開發定案會議。

## 1. 需求背景

搜尋行為正在從傳統搜尋結果頁轉向 AI 直接回答。品牌經營的觀察重點不只是在 Google 排名第幾，而是 AI 回答中是否提及品牌、是否引用品牌內容、品牌在競品之間的相對能見度，以及 AI 對品牌的正負面描述。

本功能目標是在目前 SEO 後台新增 GEO 分析能力，讓 Titan 能追蹤客戶品牌在 ChatGPT、Gemini、Claude、Perplexity、Google AIO 等 AI 搜尋或回答平台中的表現，並把檢測結果轉換成可執行的內容優化建議與客戶報告。

## 2. 產品定位

一句話定位：

> 一套追蹤品牌在各大 AI 搜尋平台「被提及、被引用、排名、輿情」的 GEO 檢測平台，把不可見的 AI 行為可讀化，並轉成內容優化行動。

產品策略：

- 先服務 Titan 既有客戶，由內部團隊使用。
- 資料層需保留 `workspace_id` 或等價租戶欄位，未來可擴充成 SaaS。
- 第一階段不開發 AI 文案生成系統，只輸出文案 Brief，文案生成暫由人工操作 Claude 完成。

## 3. 核心使用流程

1. 使用者建立品牌、競品、目標市場與追蹤設定。
2. 使用 Query Research 工具輸入關鍵字、取得搜尋量、選擇搜尋意圖，產生要追蹤的 AI 問句。
3. 使用者將問句加入 Query / Topic 管理。
4. 跑題引擎依排程把問句送到各 AI 平台。
5. 系統保存每次平台回應、地區、語言、時間戳與來源資料。
6. 解析層擷取品牌提及、排名、引用來源、產品、主題與輿情。
7. 指標引擎每日聚合能見度、SOV、平均排名、引用採用率等指標。
8. 儀表板呈現趨勢、競品對標、缺口與機會點。
9. 系統產出優化行動建議與客戶報告。
10. Phase 2 匯出文案 Brief，交給 Claude 人工產文案。

## 4. MVP 範圍

MVP 目標是先驗證核心 GEO 檢測能力，並能形成可交付客戶的報告。

MVP 必做項目：

- 資料模型與品牌 / 競品設定。
- Query Research 工具。
- Query / Topic 管理。
- 跑題引擎，串接 4 個官方 API 與 Google AIO SERP 資料源。
- 解析品牌提及、排名、引用與輿情。
- 指標引擎與前期比較。
- GEO 儀表板。
- 競品對標。
- AI 回應檢視。
- 多地區第一版：台灣與美國。
- 優化行動建議。
- 客戶報告匯出。

## 5. 功能模組需求

### 5.1 品牌、競品與 Workspace 設定

優先級：MVP

功能內容：

- 建立客戶 / workspace。
- 建立品牌名稱、品牌別名、英文名、縮寫與主要網址。
- 設定競品清單，可供 SOV、能見度差、Query 層級 Better Performer 計算。
- 設定目標市場，MVP 支援台灣與美國。
- 設定語言與地區參數，例如台灣中文、美國英文 B2B。
- 標記品牌字與非品牌字，品牌字 Query 主要追蹤輿情，並可降頻執行以控制成本。
- 保留 SaaS 擴充所需租戶隔離欄位。

### 5.2 Query Research 工具

優先級：MVP；URL 模式與 GSC 模式為 Phase 2

功能內容：

- 關鍵字輸入，最多 10 個。
- 選擇地區與語言。
- 透過 Google Keyword Planner / Google Ads API 取得搜尋量，需依地區與語言取數。
- 搜尋意圖多選：
  - 導航
  - 資訊
  - 商業
  - 交易
- 支援 Branded / Non-Branded 切換。
- 依目標市場語氣產生問句：
  - 台灣市場：台灣中文語氣。
  - 美國市場：英文 B2B 採購語境。
- 美國 B2B 外銷問句需支援採購評估、供應商比較、替代方案等意圖。
- 提供 Shortlist 收藏。
- 提供 Show More Prompts。
- 提供相關關鍵字建議。
- 產生結果表，欄位至少包含：
  - Prompt
  - Keywords
  - Intent
  - 動作，例如加入追蹤、收藏、展開更多。
- Phase 2 增加 URL 模式與 GSC 模式，競品可先標示 Coming Soon。

### 5.3 Query / Topic 管理

優先級：MVP；批次匯入為 Phase 2

功能內容：

- 支援手動輸入單題 Query。
- 支援多題輸入。
- Query 可掛到 Topic。
- Query 可設定地區、語言與目標市場。
- Query 可勾選要追蹤的指標。
- Query 可設定 Metadata 標籤。
- Query 可標記是否為品牌字。
- Query 可啟用 / 停用。
- 排程選項：
  - 立即跑。
  - 下個週期跑。
- Phase 2 支援 Bulk Import。

### 5.4 跑題引擎與 AI 平台串接

優先級：MVP；DeepSeek、Copilot、AI Mode 為 Phase 2

MVP 平台：

- Perplexity：使用原生 citations。
- ChatGPT：使用 OpenAI Responses API 搭配 web 能力。
- Gemini：使用 Search grounding。
- Claude：追蹤提及與輿情。
- Google AIO：透過第三方 SERP API，例如 SerpApi 或 DataForSEO。

功能內容：

- 每題每平台每日預設執行 1 次。
- 支援立即執行與排程執行。
- 保存原始回應內容。
- 保存平台、地區、語言、執行時間、Query、Topic、workspace 等上下文。
- Google AIO 需支援地區參數，例如 `gl`、`hl`、`location`。
- 官方 API 需透過 prompt 與問句地理脈絡引導目標市場。
- 成本控管：
  - Query 啟停開關。
  - 品牌字可降頻為每週。
  - 輿情判讀使用較低成本模型。
  - 保存執行紀錄與 API 成本估算。

### 5.5 回應解析

優先級：MVP

功能內容：

- 從 AI 回應中解析品牌是否被提及。
- 解析品牌在回答中出現的相對排名。
- 同一回應中同一品牌多次提及只計 1 次。
- 解析競品提及。
- 解析引用來源 URL 與 domain。
- 解析引用來源是否為自有網站。
- 解析產品、服務、主題與常見陳述。
- 解析正面 / 負面 / 中性輿情。
- 保存結構化解析結果，並可回溯到原始回應。

### 5.6 核心指標

優先級：MVP

所有指標都需支援與前期比較，例如 `+1.9pp`、`-0.4pp`。

指標定義：

- Visibility 能見度：提及品牌的回應數 / 回應總數 * 100%。
- SOV 聲量佔比：你品牌提及數 / 你品牌與所有競品提及數。
- Position 平均排名：回應中品牌第幾個被提到，只計算有提到品牌的回應。
- Mentions 品牌提及：提及品牌的回應數 / 回應總數，例如 `729/862`。
- Used % 引用採用率：某 URL 被引用的回應數 / 總回應數。
- Share % 引用份額：某 URL 引用次數 / 所有總引用次數。

### 5.7 儀表板

優先級：MVP

功能內容：

- 顯示品牌整體 GEO 表現。
- 顯示 Visibility、SOV、Position、Mentions、Used %、Share %。
- 顯示各指標與前期比較。
- 顯示趨勢、缺口與機會點。
- 支援依 workspace、品牌、Topic、Query、平台、地區、時間區間篩選。
- 顯示競品對標摘要。
- 顯示需優先處理的負面輿情與低能見度主題。

### 5.8 輿情分析

優先級：MVP；趨勢圖為 Phase 2

功能內容：

- 判讀 AI 回應中與品牌相關的正面、負面、中性描述。
- 計算正面 / 負面 / 中性數量。
- 擷取 Theme。
- 擷取 Statement。
- 提供負面等於機會的檢視，指出可透過內容修正或補強的議題。
- Phase 2 補上輿情趨勢圖。

### 5.9 引用來源分析

優先級：MVP；Watched URLs 為 Phase 2

功能內容：

- 顯示 Citation Count。
- 顯示 Used %。
- 顯示 Share %。
- 區分自有引用與非自有引用。
- 支援 By URL 檢視。
- 支援 By Domain 檢視。
- 支援來源 Type 分類。
- Phase 2 支援 Watched URLs，讓使用者指定重點 URL 追蹤引用變化。

### 5.10 回應檢視

優先級：MVP

功能內容：

- 顯示 AI 回應列表。
- 支援 All / Mentioned 篩選。
- 支援依平台、地區、Query、Topic、時間篩選。
- 單筆回應提供細節側欄。
- 細節側欄至少顯示：
  - 原始 Prompt。
  - AI 平台。
  - 回應內容。
  - 提及品牌與競品。
  - 品牌排名。
  - 產品或服務。
  - 引用 URL。
  - 輿情判讀。

### 5.11 競品分析

優先級：MVP；Topics 維度為 Phase 2

功能內容：

- 選定競品進行對比。
- 顯示能見度差。
- 顯示 SOV 差。
- 顯示 Query 層級 Better Performer。
- 挖掘品牌相對競品的缺口。
- 顯示競品贏的 Query 與可能原因。
- Phase 2 增加 Topic 維度分析。

### 5.12 優化行動建議

優先級：MVP

功能內容：

- 檢測後告訴使用者為什麼分數低。
- 建議需要補強的內容類型，例如 FAQ、結構化內容、主題叢集。
- 根據 Query 缺口、負面輿情、競品贏的題目，產出可行動的優先順序。
- 建議內容需能對應既有 SEO 交付物與客戶溝通。

### 5.13 客戶報告匯出

優先級：MVP

功能內容：

- 一鍵產出客戶可讀的 PDF 或 PPT。
- 報告需呈現 GEO 檢測價值，作為月費服務交付物。
- 報告內容至少包含：
  - 本期摘要。
  - 核心指標與前期比較。
  - AI 平台表現。
  - 地區表現。
  - 競品對標。
  - 主要正負面輿情。
  - 引用來源。
  - Query 缺口與機會。
  - 下期優化建議。

### 5.14 文案 Brief 匯出

優先級：Phase 2

功能內容：

- 將 Query 缺口、負面輿情、競品贏的題目整理成結構化文案需求單。
- Brief 內容至少包含：
  - 客戶 / workspace。
  - 品牌。
  - 目標市場。
  - 目標語言。
  - Query / Topic。
  - 搜尋意圖。
  - 目前問題。
  - 競品贏點。
  - 需要補強的內容重點。
  - 建議標題或內容架構。
  - 建議 FAQ。
  - 引用或參考 URL。
  - 給 Claude 的可貼上 prompt 區塊。
- 不在此階段內建 AI 文案生成。

### 5.15 核心 / 衛星文章架構建議

優先級：Phase 2

功能內容：

- 依 Query 缺口與意圖分群。
- 自動建議 pillar / satellite 架構。
- 對應既有 SEO 內容交付物。
- 可與文案 Brief 匯出串接。

### 5.16 變化告警

優先級：Phase 2

功能內容：

- 指標大幅下滑時主動標記。
- 競品突然超車時主動標記。
- AI 開始引用新來源時主動標記。
- 告警需能連回相關 Query、回應與指標變化。

### 5.17 競品內容缺口反查

優先級：Phase 2

功能內容：

- 針對競品贏的 Query，反查 AI 引用了競品哪些頁面或網域。
- 協助判斷自家需要對標或補強的內容。
- 可輸出到優化建議或文案 Brief。

### 5.18 已優化內容成效追蹤

優先級：Phase 3

功能內容：

- 標記某篇內容是為了攻某個 Query 或 Topic 而寫。
- 追蹤發布後該 Query 或 Topic 的能見度是否上升。
- 支援內容、Query、指標變化之間的關聯檢視。

### 5.19 多客戶總覽 Agency View

優先級：Phase 3

功能內容：

- 跨 workspace 總覽每個客戶本週表現。
- 標示需要優先關注的客戶。
- 顯示核心指標異常、競品超車、負面輿情增加等狀態。

### 5.20 排程化報告寄送

優先級：Phase 3

功能內容：

- 每週或每月自動寄送客戶報告。
- 支援寄送對象設定。
- 支援寄送紀錄與失敗重試。

## 6. 技術與資料源決策

AI 平台資料取得：

- ChatGPT、Gemini、Claude、Perplexity 走官方 API。
- Google AIO 走第三方 SERP API。
- 不自建爬蟲，避免反爬與維護成本。

搜尋量資料源：

- 使用 Google Ads API / Google Keyword Planner。
- 因 Titan / WINHO 有實際投放資料，可取得實際搜尋量，補足競品中文搜尋量容易為 0 的問題。

地區策略：

- MVP 支援台灣與美國。
- 架構保留日本、歐洲等多地區擴充。
- 地區需是一級概念，不應只藏在 Query 字串中。

成本策略：

- 每題每平台每日 1 次為預設。
- 支援 Query 啟停。
- 品牌字降頻。
- 輿情判讀使用較低成本模型。
- 需可追蹤 API 使用量與成本。

## 7. 不做範圍

現階段不做：

- AI 文案生成系統。
- 自建 Google AIO 爬蟲。
- 完整 SaaS 商業化功能。
- 日本、歐洲等非 MVP 地區。
- DeepSeek、Copilot、AI Mode 平台。

## 8. 開發階段建議

目標：核心檢測加上可立即交付客戶。

內容：

- 資料模型與品牌競品設定。
- Query Research。
- Query / Topic 管理。
- 跑題引擎。
- 平台串接：Perplexity、ChatGPT、Gemini、Claude、Google AIO。
- 解析：提及、排名、引用、輿情。
- 指標引擎與前期比較。
- 儀表板、競品對標、回應檢視。
- 多地區：台灣、美國。
- 優化行動建議。
- 客戶報告匯出。

### Phase 2：閉環與洞察

目標：補齊檢測後的行動與內容閉環。

內容：

- 文案 Brief 匯出。
- 核心 / 衛星文章架構建議。
- 變化告警。
- 競品內容缺口反查。

- 輿情趨勢圖。
- Watched URLs。
- 平台擴充：DeepSeek、Copilot、AI Mode。

### Phase 3：規模化

目標：自動化、Agency 管理與未來 SaaS 化。

內容：

- 多客戶總覽 Agency View。
- 排程化報告寄送。
- 產品分析。

- GA4 串接。

- 地區擴充：日本、歐洲。

## 9. 需要拍板或補充的問題

- Phase 1 預計工期與人力分工：後端引擎、前端、資料解析、報告產製各由誰負責。
- SERP API 廠商選型：SerpApi 或 DataForSEO。
- Google Ads API token 申請與可用帳戶。
- 客戶報告格式第一版要 PDF、PPT，或兩者都要。
- 儀表板是否直接整合在既有 SEO 後台導覽中，或先做獨立入口。
- MVP 是否需要權限控管到 workspace 層級，或先沿用既有後台權限。
- 各 AI 平台回應保存期限與成本上限。

## 10. 驗收條件草案

- 使用者可建立品牌、競品、地區與 Query。
- 使用者可透過 Query Research 從關鍵字產生追蹤問句。
- 系統可對 MVP 平台執行 Query 並保存原始回應。
- 系統可解析提及、排名、引用與輿情。
- 儀表板可顯示核心指標與前期比較。
- 使用者可查看單筆 AI 回應與解析結果。
- 使用者可比較品牌與競品表現。
- 系統可產出優化行動建議。
- 系統可匯出客戶報告。
- MVP 可分別追蹤台灣與美國市場。
